# DelQuant Platform Brief

## An independent NBA intelligence layer for products that need more than a number

Your customers can already get projections. The harder product problem is giving them a reason to trust, compare, and act on those projections.

DelQuant provides a focused NBA model layer that can replace an existing projection source or work beside it. It adds player context, uncertainty, historical shape, roster archetypes, and reproducible evaluation through API, JSON, batch, and report-ready outputs.

## What DelQuant adds

### Independent projections

Season projections, current-form views, game-day context, projected minutes, category outputs, uncertainty, and confidence. Use a structural season view or a more responsive recent-window view when the decision requires it.

### Explainable player intelligence

Each player can be evaluated through role, risk, durability, archetype, competitive traits, historical comparisons, and capability flags—not just a single forecast number.

### Historical context

Compare a player with similar historical player-seasons and inspect how comparable profiles developed, performed, and fit inside winning roster structures.

### Roster and decision layers

Use archetype and competitive-trait outputs for player evaluation, roster construction, content, research, and internal decision workflows.

### Evaluation that can be checked

DelQuant supports dated historical replay with no-lookahead behavior. A prospective customer can test DelQuant against its current source, baseline, or internal model using an agreed player universe and evaluation window.

## Where it fits

DelQuant is designed for analytics providers, fantasy platforms, sports media, sportsbooks, and teams that want to add differentiated NBA intelligence without rebuilding the model, historical context, and delivery layer themselves.

The integration can be narrow:

- enrich an existing player card;
- add a second opinion beside a current projection feed;
- power a historical-comparison or archetype feature;
- add uncertainty and confidence to a bare point estimate;
- provide a deeper API or batch feed for internal analysts;
- test a complete replacement for a current NBA projection source.

## Why this is commercially useful

- **Differentiate the product:** Give customers player context and analysis they cannot get from a commodity feed alone.
- **Reduce build time:** Start with a working intelligence layer instead of assembling the historical archive, model logic, and evaluation surface from scratch.
- **Improve explainability:** Make it easier for product, editorial, and customer-facing teams to answer “why this projection?”
- **Create a measurable pilot:** Keep DelQuant only if it improves the forecast, the explanation, or the product experience.

## Integration surface

The public API surface includes:

- current projections and game-day projections;
- responsive projection horizons;
- no-lookahead historical replay;
- player profiles and historical comparisons;
- advanced archetypes and competitive traits;
- lineup, similarity, streaming, and trade-analysis tools;
- controlled partner feeds for higher-granularity baseline fields.

The service is available through JSON API delivery and scheduled data workflows. Credentials, limits, and commercial terms are scoped during onboarding.
