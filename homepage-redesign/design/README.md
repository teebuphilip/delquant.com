# DelQuant front page design

The visual target is [direction.png](./direction.png), generated with the built-in ImageGen tool from a screenshot of the public DelQuant home page.

## Design prompt

> Production-quality, scrollable desktop landing page for DelQuant, an NBA intelligence platform. Premium sports editorial meets quantitative research lab. Deep midnight navy and near-black foundation, warm ivory typography, electric yellow highlights, restrained copper basketball accents. Oversized display type, dramatic basketball analytics hero, data-driven player-intelligence preview, buyer outcome cards, methodology, and a decisive contact path. Preserve the B2B premise: projections, risk, archetypes, historical comps, and decision products. Avoid stock photos, fake logos, lorem ipsum, and browser chrome.
