Summary

This page is meant to show how team-level HBB sits on top of the player-level FMV stack without changing the player comparison baseline.

Stage Order

1. FMV Salary-equivalent market value from the simulation layer.
2. FMVW Translate market value into wins against the replacement baseline.
3. HBB Apply team context as a multiplicative adjustment to the wins bridge.
4. Proxy read Show the offense and defense box-score proxies, plus FTA and turnovers, as a separate diagnostic layer.
5. Gap Report the pair gap at each bridge stage so the arithmetic is visible.
