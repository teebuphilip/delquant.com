01 · Quickstart

Make your first request.

Set the service URL and API key supplied with your access. Resolve a canonical player ID first, then call the projection or profile endpoint you need.

export DELQUANT_BASE_URL="https://your-delquant-api.example.com" export DELQUANT_API_KEY="YOUR_API_KEY" curl "$DELQUANT_BASE_URL/players/lookup?query=Shai%20Gilgeous-Alexander&limit=1" \ -H "X-API-Key: $DELQUANT_API_KEY"

The production service URL and credentials are issued during the technical handoff. Do not commit API keys to source control.

02 · Authentication

Restricted service-to-service access.

Protected endpoints use the X-API-Key request header. Public documentation contains schemas and examples; credentials are provided separately.

X-API-Key: YOUR_API_KEY
  • 200 request succeeded
  • 401 missing or invalid key
  • 404 valid request, player/date/artifact unavailable
  • 422 invalid parameter or request body
  • 503 required service configuration unavailable

03 · Projections

Core projection endpoints.

GET/health

Check service liveness and API version.

{"status":"ok","engine":"delquant","version":"1.0.0"}
GET/players/lookup

Resolve a player name, team, position, or DelQuant ID to the canonical player identity used by downstream calls.

GET /players/lookup?query=203999&limit=10 {"query":"203999","players":[{"player_id":"203999","name":"Example Player","team":"DEN","position":"C"}],"count":1}
GET/projections/today

Return the current projection contract, including player identity, projected minutes, category forecasts, uncertainty, and confidence.

{"players":[{"player_id":"203999","name":"Example Player","team":"DEN","position":"C","projected_minutes":34.2,"pts":26.8,"pts_std":5.42,"pts_conf":0.72,"reb":12.1,"reb_std":2.88,"ast":8.9,"ast_std":2.41}]}
GET/api/game-day/projections

Return a dated slate with opponent, location, rest, projected minutes, and per-stat uncertainty.

GET /api/game-day/projections?date=YYYY-MM-DD&include_contextual_variance=false
GET/api/local/historical-projections

Return no-lookahead historical projections for a past decision date.

GET /api/local/historical-projections?date=2025-01-15&seasons=3&use_game_day=false

04 · Player intelligence

Go beyond the point estimate.

GET/api/team/player-profile

Return a combined player view with projection, variance, risk, archetype profile, competitive traits where available, and historical comparisons.

GET /api/team/player-profile?player_name=Shai%20Gilgeous-Alexander&comp_count=5
GET/api/comps/search

Search current players and return available historical comparison matches.

GET/api/comps/player/{player_id}

Return historical comparisons for one canonical player ID.

GET/tools/roster-construction/archetype-advanced/summary

Access advanced archetype research summaries and position-relative player-shape context.

05 · Decision tools

Use the model inside workflows.

POST/tools/lineup/optimize

Build a lineup from a candidate pool and projection inputs.

GET/tools/similar-players

Find comparable current players using the model’s player-shape layer.

POST/tools/trade/analyze

Analyze a trade or roster decision using projection and player-context outputs.

06 · Operations

Designed for scheduled production use.

  • Projection refresh: nightly, with optional morning refresh.
  • Initial package: pre-game and scheduled delivery, not live in-game updates.
  • Consumers should retain both their universal player ID and DelQuant’s canonical player_id.
  • A valid request with no available player, date, or artifact returns 404; do not convert that into a successful empty response.
